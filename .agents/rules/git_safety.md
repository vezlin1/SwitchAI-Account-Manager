# Git Safety Rules

- **НИКОГДА не коммитить (`git commit`)** без явного подтверждения или прямого запроса пользователя.
- **КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО пушить (`git push`)** в удалённый репозиторий без прямого указания пользователя.
- Не производить деструктивные операции над ветками или историей Git без согласования.
