## Supported versions

Security fixes are provided for the latest available version of SwitchAI. If
you are using an older version, update the app first and check whether the
problem still occurs.

## Reporting a security problem

If you find a vulnerability or notice suspicious behavior, please do not open
a public Issue. Send a private report through
[GitHub Security Advisories](https://github.com/vezlin1/SwitchAI-Account-Manager/security/advisories/new).

Please include:

- your SwitchAI version and operating system;
- what happened and what you expected;
- simple steps that reproduce the problem;
- safe log excerpts or screenshots, if they are helpful.

## Information you should not send

Never attach:

- passwords or verification codes;
- OAuth tokens or the contents of authentication files;
- SwitchAI vault files;
- complete logs that may contain personal information.

Remove names, email addresses, account identifiers, and other personal details
before sending your report.

## What happens next

We will review the report and respond as soon as practical. Please avoid
publishing the details before a fix is available, as doing so may put other
users at risk.
