# Project Rules & Guidelines: SwitchAI Account Manager

## ⚠️ Git & Version Control Restrictions (Strict)

1. **NO COMMITS WITHOUT EXPLICIT PERMISSION**:
   - **НИКОГДА не делать `git commit`** (или аналогичные действия через скрипты/инструменты), пока пользователь прямым текстом не попросит сделать коммит (например: «закоммить», «сделай коммит»).
   - Даже если задача полностью завершена или тесты прошли успешно — НЕ коммитить автоматически.

2. **ABSOLUTE BAN ON `git push` WITHOUT DIRECT COMMAND**:
   - **КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО выполнять `git push`** (отправку изменений в удалённый репозиторий) без прямого указания пользователя.
   - Любые push-операции должны производиться только по прямому запросу пользователя («запушь», «push to remote»).

3. **General VCS Safety**:
   - Запрещено автоматически выполнять деструктивные или изменяющие историю команды (`git reset --hard`, `git checkout .`, `git rebase`, `git merge`) без согласования.
